# Bilim AI — цифровой помощник учителя / Мұғалімнің цифрлық көмекшісі

Веб-приложение на Streamlit для подготовки учебных материалов и демонстрации анализа учебных данных. Интерфейс поддерживает русский и казахский языки. Учитель выбирает задачу, вводит исходные данные и получает материал для последующей проверки и использования на уроке.

Публичное приложение: [ai-teacher-astana.streamlit.app](https://ai-teacher-astana.streamlit.app/). Этот README описывает код в репозитории; опубликованная версия может отличаться до её обновления.

## Инструменты учителя

| Модуль | Результат | Нужен Gemini API key |
| --- | --- | --- |
| Генератор карточек / Тапсырма карточкалары | Карточки и отдельные ответы для учителя в DOCX; оба файла в ZIP | Нет для встроенного примера, Excel и Google Таблиц; да для создания вопросов через ИИ |
| Задачник Python / Python есептер жинағы | 25 задач PizzaBot и Mars OS с примерами. Для новой задачи доступны отдельные TXT для ученика и учителя | Для готового банка ключ не нужен. Генерация использует Gemini |
| Календарно-тематический план / Күнтізбелік-тақырыптық жоспар (КТЖ) | Проект плана в DOCX по темам или PDF, с распределением по четвертям | Да |
| Конструктор КСП / ҚМЖ конструкторы | Проект краткосрочного плана урока в DOCX | Да |
| Анализ успеваемости / Үлгерімді талдау | Статистика и графики встроенного примера или Excel; экспорт статистики в CSV | Нет |
| Демонстрация ML / ML демонстрациясы | Пример классификации по введённым показателям | Нет |
| Проверка по фото / Фото арқылы тексеру | Предварительный разбор учебной работы; экспорт в DOCX и TXT | Да |
| Педагогическая характеристика / Педагогикалық мінездеме | Черновик по заданным фактам; экспорт в DOCX и TXT | Да |
| Разминки и интерактивы / Сергіту сәттері | Три упражнения на выбор по теме и классу; экспорт в DOCX и TXT | Да |

Карточки из готового банка создаются программно: API-ключ не требуется для подбора заданий и подготовки DOCX. Для Google Таблиц дополнительно нужны интернет и доступ к чтению таблицы.

В «Задачнике Python» можно создать задачу с нуля или выбрать «Взять за основу новой задачи» в готовом банке. Укажите класс и уровень. Например, попросите придумать задачу на цикл `for` про покупки на школьной ярмарке. Gemini подготовит условие, примеры ввода и вывода, подсказку и решение для учителя. Перед раздачей сверьте решение с примерами. Готовые задачи адаптированы из [авторского сюжетного практикума Python](https://github.com/mcjuba1996-sudo/Python).

## Быстрая демонстрация без API-ключа

1. Откройте генератор карточек и выберите встроенные демонстрационные данные.
2. Задайте количество заданий по уровням сложности. Сумма должна быть больше нуля; в банке должно хватать заданий каждого выбранного уровня.
3. Создайте варианты и скачайте оба файла: карточки и ответы. Для одного скачивания выберите ZIP.
4. Откройте DOCX и сопоставьте номера заданий с ответами. Повторите сценарий на казахском языке.

Для собственного банка скачайте Excel-шаблон из приложения. Его структура зависит от выбранного языка; импорт Excel поддерживает обе версии:

| Язык шаблона | Лист вопросов и его колонки | Лист учеников и его колонка |
| --- | --- | --- |
| Русский | `Банк_вопросов`: `Вопрос`, `Ответ`, `Сложность` | `Ученики`: `ФИО` |
| Қазақша | `Сұрақтар_банкі`: `Сұрақ`, `Жауап`, `Қиындық` | `Оқушылар`: `Аты-жөні` |

Названия колонок — формат обмена, а не требование вводить настоящие ФИО. В шаблонах стоят обозначения `DEMO-01…03`; можно использовать `Ученик 01` или `Оқушы 01`.

Для совместимости используйте уровни `Легкий`, `Средний`, `Сложный` либо `Жеңіл`, `Орташа`, `Қиын`. Напишите сами вопросы и ответы на нужном языке: переключение интерфейса не переводит содержимое загруженного банка автоматически.

Для Google Таблиц используйте структуру русского или казахского Excel-шаблона из таблицы выше: поддерживаются оба варианта названий листов и колонок. Таблица должна быть доступна для чтения по ссылке без входа в аккаунт. После ввода ссылки нажмите «Загрузить таблицу». Если содержимое Google Таблицы изменилось, загрузите её повторно и заново создайте карточки. Не публикуйте таблицы с реальными персональными данными.

## Параметры планов и разминок

В КТП задайте учебный год, количество четвертей, недель в каждой четверти и часов в неделю. Приложение вычисляет количество уроков как сумму `недели × часы в неделю` по четвертям. Начальные значения недель — редактируемый пример, а не утверждённый календарь вашей школы.

КТП создаётся последовательными запросами к ИИ по четвертям, затем проверяется общее количество и нумерация уроков. Прогресс показывает текущую четверть. Один запуск может сделать несколько запросов к сервису; время зависит от выбранного объёма и ответа Gemini. Если одна часть не прошла проверку, новый итоговый документ не создаётся. Темы, цели и педагогическую последовательность учитель проверяет отдельно.

Для КСП укажите предмет, класс, тему и цель из своей программы. Для разминок длительность в интерфейсе относится **к одной разминке**: приложение предлагает три варианта на выбор, каждый с указанной длительностью.

## Локальный запуск

Требуется Python 3.12. Команды для PowerShell из папки проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Откройте локальный адрес, который выведет Streamlit. При размещении на Streamlit Community Cloud укажите `app.py` как основной файл и используйте Python 3.12.

## Настройка Gemini

ИИ-модули используют ключ, введённый пользователем в боковой панели, либо серверный secret `DEFAULT_API_KEY`. Без ключа доступны готовые задачи Python, карточки из готового банка, анализ Excel и демонстрация ML.

Для локальной настройки скопируйте `.streamlit/secrets.toml.example` в `.streamlit/secrets.toml` и заполните значения на своём компьютере. На Streamlit Community Cloud добавьте их в настройки Secrets приложения.

```toml
DEFAULT_API_KEY = ""
GEMINI_MODEL = "gemini-3.6-flash"
```

`GEMINI_MODEL` задаёт идентификатор модели; при пустом значении используется `gemini-3.6-flash`. Можно задать настройки через переменные окружения: ключи `GEMINI_API_KEY`, `GOOGLE_API_KEY` или `DEFAULT_API_KEY`, модель — `GEMINI_MODEL`. Приоритет ключа: введённый пользователем → окружение → Streamlit Secrets; для модели окружение также имеет приоритет перед Secrets. Доступность идентификатора модели, квота и доступ конкретного ключа проверяются отдельно в Gemini. Наличие значения в конфигурации не подтверждает доступность модели у провайдера.

Не добавляйте настоящий ключ в репозиторий, видео, скриншоты или материалы заявки. Общий серверный ключ может исчерпать квоту из-за суммарного использования. Подготовьте и проверьте его до демонстрации ИИ-модулей. Текст, PDF и изображения, отправляемые в ИИ-модули, передаются сервису Gemini для обработки.

## Данные и ограничения

- Используйте только вымышленные обозначения учеников и демонстрационные оценки. Для фото подготовьте собственный учебный пример без ФИО, лиц, контактов и других идентификаторов.
- КТП, КСП, характеристики и ответы ИИ — черновики. Учитель проверяет факты, формулировки, задания, ответы и соответствие своей учебной программе. Приложение не подтверждает нормативное соответствие документов.
- Проверка по фото может неверно распознать текст или пропустить ошибку. Итоговую оценку выставляет учитель.
- ML-модуль — учебная демонстрация `RandomForestClassifier`, обученная на четырёх встроенных учебных строках. Её прогнозная достоверность не установлена. Результат нельзя использовать для реального оценивания, распределения учеников по группам или педагогических решений.
- EDA показывает описательную статистику введённых данных; графики сами по себе не объясняют причины успеваемости.

```powershell
.\.venv\Scripts\python.exe -m pip install pytest

```

Workflow [`.github/workflows/tests.yml`](.github/workflows/tests.yml) настроен на `push`, `pull_request` и ручной запуск: Python 3.12, установка `requirements.txt` и `pytest`, затем `python -m pytest -q`. Ему достаточно разрешения `contents: read`; ключ Gemini для тестов не передаётся. Наличие workflow не означает, что он уже успешно выполнен: результат смотрите в GitHub Actions.

Тесты с подставными ответами API (mocks) проверяют обработку данных и поведение приложения в заданных сценариях. **Они не подтверждают работу живого сервиса Gemini**, действительность ключа, доступность модели, квоты или качество реальных ответов. Для этого нужен отдельный ручной запуск ИИ-модулей с рабочим ключом. Факт успешного прохождения конкретного запуска проверяется по выводу тестов; этот документ не является протоколом испытаний.

Каждый сценарий нужно пройти дважды: с интерфейсом `Русский` и `Қазақша`. Пустые ячейки означают, что результат проверки ещё не записан. Проверяющий отмечает результат только после фактического выполнения.

| Сценарий и ожидаемый результат | RU | KK |
| --- | :---: | :---: |

| Карточки: загрузка обоих вариантов Excel-шаблона и чтение доступной Google Таблицы с русскими и казахскими названиями листов; результат соответствует их содержимому | ☐ | ☐ |
| Карточки: ИИ-источник с рабочим ключом создаёт вопросы по выбранной теме; текст на выбранном языке | ☐ | ☐ |
| КТП: генерация по темам с заданными неделями каждой четверти и часами в неделю; число уроков, четверти и сквозная нумерация корректны; DOCX открывается | ☐ | ☐ |
| КТП: отдельная проверка загрузки корректного PDF и получения результата по его содержимому | ☐ | ☐ |
| КСП / ҚМЖ: тема и цель отражены в плане, этапы согласованы между собой; DOCX открывается, таблицы читаются | ☐ | ☐ |
| EDA: встроенный пример и свой Excel с числовым столбцом; статистика, оба графика и CSV соответствуют данным | ☐ | ☐ |
| ML: изменение показателей и повторный запуск; показан результат и явное пояснение о четырёх учебных строках и отсутствии подтверждённой достоверности | ☐ | ☐ |
| Фото: учебный снимок без персональных данных; читаемый разбор на выбранном языке; ошибки сверены вручную; DOCX и TXT открываются | ☐ | ☐ |
| Характеристика: условный ученик, класс и факты; результат соответствует вводу, не приписывает неуказанные достижения; DOCX и TXT открываются | ☐ | ☐ |
| Разминки: тема, класс и длительность одной разминки; три варианта на выбор, каждый на заданное время; DOCX и TXT открываются | ☐ | ☐ |
| Задачник Python. Выбрать задачу из обоих сюжетов, скачать условие, создать похожую задачу и сравнить ученический и учительский файлы | ☐ | ☐ |
| Навигация. Все девять модулей открываются, кнопки и подсказки понятны на выбранном языке | ☐ | ☐ |

Отдельно проверьте ошибки и повторные действия:

- Пустая тема, пустой список условных учеников, нулевое количество вопросов и недостаток вопросов нужного уровня: понятное сообщение вместо пустого документа или скрытой подмены сложности.
- Excel без нужного листа/колонки, пустой или повреждённый файл; для EDA — отсутствие числовых значений.
- Неверная или закрытая Google Таблица: понятное сообщение, сохранение возможности выбрать другой источник.
- Отсутствующий или неверный API-ключ, недоступная модель, исчерпанная квота и сбой ответа: понятная ошибка без раскрытия ключа.
- Повреждённое изображение/PDF и некорректный структурированный ответ ИИ: понятная ошибка, возможность исправить ввод и повторить.
- После получения результата скачать карточки, затем ответы и ZIP; проверить наличие обоих DOCX внутри ZIP. После изменения исходных данных увидеть предупреждение о предыдущем результате, повторить генерацию и убедиться, что скачивается актуальный результат. Старый результат сохраняется в текущем сеансе до успешного создания нового; это не постоянная история документов.
- В экспортированных документах проверить кириллицу и казахские символы `Ә Ғ Қ Ң Ө Ұ Ү Һ І`, переносы строк и таблицы.

## Қазақша қысқаша

**Bilim AI** — мұғалімге арналған Streamlit веб-қосымшасы. Мұнда тапсырма карточкалары, Python есептер жинағы, КТЖ, ҚМЖ, деректерді талдау, ML демонстрациясы, фото арқылы тексеру, мінездеме және сергіту жаттығулары бар. Интерфейсті қазақша немесе орысша таңдауға болады. Жинақтан дайын есепті алуға немесе тақырып, сынып пен деңгейді көрсетіп, Gemini арқылы жаңа есеп құрастыруға болады.

Дайын демонстрациялық деректерден, Excel файлынан немесе қолжетімді Google Кестеден карточкалар мен жауаптарды Word форматында API кілтінсіз жасауға болады. ЖИ арқылы мәтін немесе тапсырма құру үшін Gemini кілті қажет. Кілтті бүйірлік панельге енгізіңіз немесе сервердегі `DEFAULT_API_KEY` құпия параметрін баптаңыз.

Excel үлгісі таңдалған тілге сәйкес жасалады. Google Кестеде қазақша немесе орысша Excel үлгісінің парақ атаулары мен бағандарын қолдануға болады. КТЖ үшін әр тоқсанның апта санын және апталық сағат санын өз жоспарыңызға сәйкес өзгертіңіз. Сергіту уақытын бір жаттығуға есептеңіз: үш нұсқаның біреуін таңдауға болады.

Нақты оқушылардың жеке деректерін қолданбаңыз: `Оқушы 01` сияқты шартты белгілер мен оқу мысалдарын пайдаланыңыз. Фотоға аты-жөні мен басқа жеке мәліметтер түспеуі керек. ЖИ нәтижелерін мұғалім тексереді. ML моделі төрт оқу мысалымен үйретілген демонстрация ғана; болжамының дұрыстығы расталмаған. API жауабын алмастыратын тесттер Gemini сервисінің нақты жұмысын растамайды.

Көрсетілім алдында тоғыз модульді екі тілде, қате енгізулерді және файлдарды жүктеуді тексеріңіз. Байқауға сілтеме, қысқаша сипаттама, негізгі промпттар және скриншоттар немесе қысқа бейне дайындаңыз.
